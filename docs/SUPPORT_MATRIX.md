# 支持矩阵

本页定义维护者当前愿意复现、接收缺陷报告并按同一验收标准修复的环境边界。这里的“支持”是本社区项目的维护范围，不表示 CCF、NOI 或 Hydro 官方认证，也不等于容量已经签字。

产品边界和七条比赛契约见 [产品说明](PRODUCT.md)；尚未完成的认证工作见 [开源路线图](OPEN_SOURCE_ROADMAP.md)。

## 状态术语

| 状态 | 含义 |
| --- | --- |
| 已验证 | 在维护者环境中已有带日期的完整证据，且证据适用于表中指定组件与规模 |
| Alpha | 主路径已跑通，但仍有明确风险、兼容限制或独立复现缺口 |
| 目标 | 代码和资源档以此为方向，尚未完成全部验收门槛 |
| 实验性 | 仓库可能包含适配代码或历史记录，但维护者不作稳定性和兼容性承诺 |
| 不支持 | 与当前产品契约冲突，或没有足够证据，不能据此组织受支持比赛 |

## 首个维护者支持 profile

Profile 名称：**`aliyun-hydro5-pm2-direct-v1`**

这是当前唯一公开的维护者支持组合。部署者可以替换域名、比赛 ID、账号和密钥，但不能在仍使用该 profile 名称时改变表中的架构边界。

| 层 | `aliyun-hydro5-pm2-direct-v1` 边界 | 当前状态 |
| --- | --- | --- |
| OJ 控制面 | Hydro `>=5.0.1,<5.1.0`；单个 Hydro 应用进程；PM2 管理，Nix 提供 Node/Caddy 运行路径；Caddy 作为公网入口 | 已验证边界 |
| Hydro 插件 | 实时送评、座位通知和私有题目克隆插件；三个权限 `0600` 的持久幂等状态文件；私有接口只允许本机编排器调用 | 已验证边界 |
| OJ 连续性 | NOI Linux 服务独立部署；比赛操作不得把重启 Hydro、Caddy 或 OJ 主机作为正常步骤 | 强制契约 |
| 比赛云主机 | 阿里云专用 ECS，Ubuntu 22.04，16 vCPU / 64 GiB，固定 EIP | 支持配置 |
| 云网络 | 主网卡只绑定一张专属普通 basic 安全组，不挂辅助 ENI；静态 OJ `/32` 管理规则与受管学生 TCP/80 规则分离 | 强制契约 |
| 桌面镜像 | 基于官方 NOI Linux 介质构建的 `noi-linux-official:2.0` GNOME 镜像；固定不可变 image ID；`org.noi.desktop.contract=finalizer-status-v1` | 单座已验证 |
| 座位隔离 | 一名选手一个 Docker；internal 网络、ICC 关闭、独立答案 bind mount、独立凭据和资源限制 | 单座已验证 |
| 容量 | 15 个正式座位 + 2 个备用座位 | **目标，尚未容量签字** |
| 单座资源起点 | 1.5 vCPU、2.5 GiB 内存、1024 PID、1 GiB `/dev/shm`，禁用 swap | 压测起点，不是承诺 |
| 学生控制入口 | Hydro 站内消息中的 HTTPS 控制面链接，先核验比赛、座位和发放状态 | 已验证 |
| 桌面主路径 | 控制面跳转到固定 EIP 的裸 HTTP/80 noVNC，`quality=9`、`compression=2`；持续页面和 WebSocket 不经跨地域 OJ 中转 | **Alpha** |
| 桌面兼容路径 | 经 OJ HTTPS/Caddy 的同 token 代理入口，仅作为直连受限时的较慢回退 | 功能回退；未作主路径性能承诺 |
| 递交契约 | 每题网页 `.cpp` 递交优先；有网页记录时取最后一次网页版本，无网页记录时截止目录兜底；不按最高分回写 | V1 机器测试完成，需随 profile 做真人复验 |
| 截止 | 比赛 ECS 本地持久化 systemd timer 先暂停座位，再停止 nginx；控制面随后收卷 | 单座闭环已验证 |
| 关停 | 撤销受管学生规则、关闭桌面路径、清空待处理队列并让 ECS 进入停止计费状态 | 单座闭环已验证 |

### Direct HTTP Alpha 限制

`aliyun-hydro5-pm2-direct-v1` 的 direct 数据面是面向短时模拟赛的体验优先方案，不是长期公网安全基线：

- noVNC 页面、键鼠事件和画面数据在比赛 EIP 上使用明文 HTTP/WebSocket；同链路观察者可能读取或篡改流量；
- 浏览器会显示不安全连接提示，部分组织策略可能直接阻止从 HTTPS 页面跳转到 HTTP；
- 部分校园网、运营商出口、代理或防火墙可能限制裸 IP、TCP/80 或长连接；此时只能使用较慢的 HTTPS 兼容入口；
- 安全组撤销只阻止新入站，严格截止仍依赖比赛 ECS 本地 timer 冻结座位并关闭 nginx；
- 学生来源未知时临时开放较宽 CIDR 会扩大暴露面，必须受唯一 `ready` 比赛、精确规则对账和赛后撤销约束。

长期目标是让专用域名直接解析到比赛 ECS 固定 EIP，并在比赛机本地终止 HTTPS。该目标完成和验收前，不应把 direct HTTP 用于长期在线服务或高安全级别场景。

## 能力与容量状态

| 能力 | 状态 | 可以声称什么 | 不能声称什么 |
| --- | --- | --- | --- |
| 官方 GNOME 单座完整闭环 | 已验证 | 单座登录、桌面、编译、保存、递交、收卷、回传和关停已跑通 | 任意新环境无需演练即可开赛 |
| Direct HTTP 单座数据路径 | Alpha 已验证 | 单座页面、作用域 WebSocket 和完整生命周期可用 | 已解决明文风险或适配所有校园网络 |
| 官方 GNOME 15+2 | 目标 | 资源和验收方案以 15+2 设计 | 已认证 15 人容量 |
| 官方 GNOME 连续 60 分钟 | 待验收 | 已定义必须采集的性能与可靠性指标 | 已完成长稳签字 |
| 旧 XFCE 40 座 | 历史证据 | 旧镜像曾验证过链路和旧资源档 | 官方 GNOME 支持 40 人 |
| OJ HTTPS 代理桌面 | 兼容回退 | 在直连不可用时提供同 token 入口 | 与杭州 EIP 直连具有相同性能 |
| 比赛 ECS 本地 HTTPS | 路线图目标 | 这是长期公网数据面的目标架构 | 当前已经交付 |

## 平台兼容范围

| 组合 | 支持状态 | 说明 |
| --- | --- | --- |
| Hydro `>=5.0.1,<5.1.0`，单 PM2 应用进程 | 支持 profile | 当前幂等文件模型以单应用进程为边界 |
| Hydro 多应用进程或多 OJ 节点 | 不支持 | 需要数据库级唯一键和跨进程协调后重新验收 |
| 阿里云专用 16C64G ECS | 支持 profile | 仍需每个新地域、新网络和新实例完成赛前验收 |
| 阿里云其他规格 | 实验性 | 必须独立做容量测试，不能按比例推算人数 |
| 腾讯云 provider | 实验性 | 仓库包含适配代码，但不属于首个公开支持 profile |
| `custom` 部署参数 | 自助兼容接口 | 允许替换域名和网络参数，不自动获得维护者支持结论 |
| 旧 XFCE `noi-linux-sim` | 应急回退 | 不提供官方 NOI Linux 环境一致性或当前容量承诺 |
| Kubernetes | 不支持 | 15 人目标规模不需要；会引入未验收的控制面和故障模式 |
| 宿主机多 Linux 账号 | 不支持正式比赛 | 不满足当前一人一容器的隔离与单座恢复契约 |
| 非 Hydro OJ | 不支持 | 账号、比赛快照、OI 盲测和 RID 回传接口均需重新设计 |
| 长期裸 HTTP 公网服务 | 不支持 | direct HTTP 只限短时 Alpha 比赛窗口 |

## 每个新部署仍需自行验证

即使完全符合 profile，也不能跳过本地验收。至少要证明：

1. 普通 OJ 首页、登录、评测和教师实时观察在 NOI Linux 全生命周期中正常；
2. Hydro 比赛为 OI 赛制，普通学生看不到结果、分数和排行榜；
3. 镜像摘要、桌面契约、材料 revision、题目映射和 systemd 截止 timer 全部匹配；
4. 一个真实普通学生账号能完成登录、编译、保存、重复递交、源码核对与截止后拒绝；
5. 正式目录、每次递交、截止快照、源码 SHA256、OJ RID 和幂等重试一致；
6. 非 `ready`、截止、错误和关机状态下，桌面入口与受管学生规则均已关闭；
7. 比赛 ECS 最终进入停止计费状态，普通 OJ 没有因比赛恢复动作被重启。

具体操作顺序见 [教师操作手册](../deploy/CONTEST_RUNBOOK.md)。

## 提交支持请求时应提供

请先删除密钥、密码、完整 token、学生身份和答案内容，再提供：

- 精确 Git commit、镜像不可变 ID 和桌面契约标签；
- Hydro 版本、Node 版本、PM2 进程数、Caddy 版本和云实例规格；
- 使用的 profile 与经过脱敏的配置差异；
- 只读健康检查摘要、相关时间窗口的脱敏日志和最小复现步骤；
- 问题属于单座、全场、OJ 控制面、直连路径还是兼容代理路径；
- 是否已经触发截止、收卷、规则撤销和 ECS 停机。

不要在公开 Issue 中上传 `.env`、`config.yaml`、Hydro token、云 AccessKey、SSH 私钥、座位 CSV、收卷目录或真实比赛截图。
