# 统一 OJ 办赛流程

本系统只在我们的 OJ 上提供服务，不向合作教练交付独立部署、服务器账号或云密钥。

## 老师

1. 在 OJ 创建 OI 比赛，设置题目、时间和报名。
2. 在该比赛页打开“NOI Linux 考试管理”。OJ 会校验当前用户是比赛所有者或拥有比赛编辑权限，然后单点登录。
3. 在五个固定页面中按顺序完成：比赛总览 → 比赛材料 → 学生座位 → 递交与评测 → 结束与归档。
4. 比赛、报名、时间、源码、分数和排名始终在 OJ 查看。

单点登录会话只绑定入口所属的一场比赛。合作教练不能看到或操作其他教练的 NOI Linux 比赛。

## 学生

1. 只使用原 OJ 账号报名和登录，不创建第二套学生账号。
2. 考前从 OJ 站内消息收到本人座位入口。
3. 在 NOI Linux 正式答案目录写代码，用“CSP 程序回收系统”递交。
4. 每次递交都进入 OJ 评测；赛后回 OJ 查看源码和成绩。

## 技术边界

- OJ 插件入口为 `/contest/<tid>/noi-linux`。
- 入口只向比赛所有者或拥有全局比赛编辑权限的用户签发 60 秒一次性票据。
- 教师会话有效期 12 小时，仅允许访问票据内的比赛 `tid`。
- OJ 和编排服务使用已有内部共享 Token 做域分离 HMAC，票据和会话不包含密码或云密钥。
- 技术管理员 Basic Auth 只用于单点登录故障时的本站维护。
